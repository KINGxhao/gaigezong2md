改革宗网书籍 → 简体 Markdown

在 gaigezong.com 的书籍目录页一键下载全书，自动繁转简，生成单个 .md 文件。

  1. 显示浏览器书签栏（Chrome / Edge：Ctrl+Shift+B）。
  2. 把下面的按钮拖到书签栏：
    书籍转 Markdown
    拖不动时：点「复制书签代码」，新建一个书签，把代码粘贴到“网址”栏。
  3. 打开某本书的目录页（如 https://gaigezong.com/jiejing/xiduyifusuo/index.htm），点击该书签，等待右上角进度完成后自动下载。

转换规则

  • 仅字形繁转简（OpenCC t2s），不替换地区用词；引号「」『』、原文空格与错字保持原样。
  • 正文粗体、表格转为 Markdown；全书附带可跳转目录。
  • 首次使用需联网从 jsDelivr / unpkg 加载繁简词库（约 1 MB，已做完整性校验）。

注意

  • 识别正文依赖该站常见的页面版式；换新书时建议先浏览生成结果。
  • 完成后面板会列出“标题不一致”等提示，便于核对。
